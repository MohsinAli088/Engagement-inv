# Dr. Shiva Shalini & Dr. Sankalp Shashwat: Engagement invitation

A single-card animated invitation that follows `design.jpeg` (ivory arch, gold frame, florals, diyas, Ganesh and Shiva-Parvati).

```bash
npm install
npm run dev      # http://localhost:1000  (add ?skipIntro to skip the opening screen)
npm run build
```

- Wording: `invite` in `src/data/content.js`
- Layout: `src/components/Invitation.jsx` (positions are in design pixels on the 853 x 1280 grid)
- Look and motion: `src/index.css`
- Artwork: `public/images/eng/` (`bg.jpg` is the design with its text removed, so the text on top is live)
